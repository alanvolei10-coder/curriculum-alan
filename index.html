Desarrollador Backend Java

¡Hola! Soy Alan, desarrollador backend especializado en Java.

Me apasiona construir el núcleo de las aplicaciones: desde la lógica de negocio y la arquitectura, hasta la gestión de datos y la seguridad. Mi experiencia se centra en el ecosistema Spring (Spring Boot, Security y Cloud), el diseño de APIs REST y el desarrollo de microservicios. Para la gestión de la información utilizo PostgreSQL y MySQL, aseguro la calidad del código mediante pruebas con JUnit y Mockito, y gestiono los despliegues con Docker.

Además, cuento con conocimientos en desarrollo frontend (HTML, CSS, JavaScript y Bootstrap). Esta visión integral me permite entender a la perfección el ciclo de vida del software, conectando eficientemente las bases de datos con la interfaz de usuario.

Venuss

Plataforma e-commerce

De qué trata

Es una tienda en línea completa. Los clientes recorren el catálogo y compran, y quien administra el negocio controla los productos y las ventas desde un panel hecho a su medida.

Mi participación

  • Programé el backend con Spring Boot: las reglas del negocio, los productos y las ventas.
  • Con Spring Security definí quién puede entrar y qué puede hacer cada usuario.
  • Construí el panel de administración para manejar el catálogo y revisar las ventas.
  • Me encargué de publicar el sitio: contenedores Docker, Nginx como servidor web y AWS S3 para los archivos estáticos.
